# 구글 시트 게임 기록 연동

이 폴더에는 게임을 끝까지 완료했을 때 기록을 시트에 추가하는 구글 앱스 스크립트 코드가 있습니다.
게임 기록을 저장한 직후 `finishtime`이 빠른 상위 3개 기록도 같은 요청의 응답으로 반환합니다. `doGet`은 저장된 순위를 다시 조회하며, 완료 화면의 새로고침 버튼에서 사용합니다.

## 저장되는 열

스프레드시트의 `시트1` 첫 번째 행을 다음 순서로 둡니다.

| 열 | 저장 값 |
| --- | --- |
| `timestamp` | 기록이 저장된 날짜와 시간 |
| `name` | 시작 화면에서 입력한 플레이어 이름 |
| `score` | 게임 시도 횟수. 적을수록 좋은 기록입니다. |
| `finishtime` | 완료 시간 (`분:초`, 예: `01:24`) |

완료 화면에는 시트에 저장된 유효 기록을 `finishtime` 오름차순으로 정렬한 상위 3명이 표시됩니다. 시간이 같으면 먼저 시트에 저장된 기록이 앞에 표시됩니다. Apps Script는 텍스트 또는 구글 시트가 시간으로 자동 변환한 값을 모두 읽으며, 새 기록의 완료 시간은 텍스트 형식으로 저장합니다.

## 앱스 스크립트 배포

1. [게임 기록 시트](https://docs.google.com/spreadsheets/d/1a1Pk1OVeyOZzsIcrmExtK-odx0gGKqEXKjLrqL8SV84/edit)를 엽니다.
2. **확장 프로그램 → Apps Script**를 열고 `Code.gs` 내용을 붙여넣은 다음 저장합니다.
3. 처음 배포하는 경우 **배포 → 새 배포 → 웹 앱**을 선택합니다. 실행 권한은 본인, 액세스 권한은 모든 사용자로 설정하고 배포합니다.
4. 코드를 수정해 다시 배포하는 경우 **배포 → 배포 관리 → 기존 웹 앱 배포 수정**을 선택하고 버전을 **새 버전**으로 바꿔 업데이트합니다. 기존 배포를 업데이트하면 URL을 바꾸지 않아도 됩니다.
5. 첫 배포라면 배포가 끝난 뒤 `/exec`로 끝나는 웹 앱 URL을 복사합니다.

웹 앱 주소는 공개 엔드포인트입니다. 주소가 외부에 알려지면 다른 사용자도 시트에 기록을 보낼 수 있습니다. Apps Script를 업데이트한 뒤에도 `저장 권한을 확인할 수 없습니다.`가 표시되면 기존 배포가 새 버전으로 갱신됐는지 확인하세요.

## Next.js 설정

프로젝트 루트의 `.env.local`에 아래 키로 웹 앱 URL을 설정합니다.

```dotenv
NEXT_PUBLIC_GOOGLE_SCRIPT_URL="https://script.google.com/macros/s/배포_ID/exec"
```

코드는 해당 값을 Next.js 서버의 `/api/scores` 경로에서 읽어 Apps Script를 호출합니다. 값은 `.env.local` 또는 배포 환경의 환경 변수에 설정하고, 변경 뒤에는 개발 서버를 다시 시작하세요.

## 저장 시점

모든 과일 짝을 찾아 게임 완료 화면에 도달할 때만 `/api/scores`가 기록을 전송하고 순위 데이터를 받아옵니다. 완료 화면의 새로고침 버튼은 기록을 추가하지 않고 현재 상위 3개를 다시 불러옵니다. 일시 정지, 게임 다시 시작, 처음 화면으로 이동, 진행 중 창 닫기에서는 기록을 보내지 않습니다. Apps Script 코드를 갱신한 경우 기존 웹 앱 배포를 새 버전으로 업데이트해야 저장과 순위 조회가 작동합니다.
